Mimir records what your coding agents attempted, which models and files were
involved, what failed, and whether the work actually landed. The Worker,
storage, and private dashboard run inside your Cloudflare account.

A session is one episode of agent work, not a bag of disconnected requests.
Mimir reconstructs the task, repository, models, duration, and token use — plus
the redacted proxy exchanges, touched files, real error signals, and evidence of
whether the work landed or was discarded.

## The private dashboard

<img src="/images/mimir-dash-screenshot.png" alt="Mimir private dashboard showing captured coding-agent sessions, outcomes, capture state, models, and token usage." loading="lazy" />

The dashboard keeps sessions, outcomes, capture state, harnesses, models, and
token usage visible in one place. It leads with sessions; requests remain
one click away when you need the raw record.

## Start here

Install the latest checksum-verified release:

```bash
curl -fsSL https://raw.githubusercontent.com/cloudboy-jh/mimir/master/install.sh | sh
```

Windows PowerShell:

```powershell
irm https://raw.githubusercontent.com/cloudboy-jh/mimir/master/install.ps1 | iex
```

Then either explore locally with [`mimir demo`](/installation/#try-it-locally)
or [create a deployment](/installation/#create-a-deployment) with
`mimir setup`.
