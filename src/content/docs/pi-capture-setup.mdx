Mimir captures completed turns from Pi and Oh My Pi across OpenRouter and
direct providers. The shared memory skill retrieves prior sessions and evidence.

## Pi

### Install

```bash
mimir install --harness pi
```

Restart Pi after installing or updating the extension.

### How capture works

- **OpenRouter:** traffic routes through Mimir with exact session, repository,
  and harness metadata.
- **Direct providers:** completed turns and exposed tool results are uploaded as
  bounded reconstructed exchanges.
- **Memory:** the `mimir-use` skill retrieves prior sessions, decisions, and
  evidence.

---

## Oh My Pi (OMP)

### Install

```bash
mimir install --harness oh-my-pi
```

Restart `omp` after install or update.

### How capture works

- Capture activates on the first completed turn, so idle drafts create no
  dashboard session.
- OpenRouter traffic and bounded direct-provider evidence use the same capture
  model as Pi.
- Lifecycle heartbeats keep active sessions current.

## Verify

Complete a turn after restarting the harness, then check its durable receipt:

```bash
mimir session status <session-id>
```

<details>
	<summary>Extension locations</summary>

	Pi installs to `~/.pi/agent/extensions/mimir.ts`. Set
	`PI_CODING_AGENT_DIR` to use another Pi agent directory.

	Oh My Pi installs to `~/.omp/agent/extensions/mimir.ts` or the active OMP
	profile. Set `OMP_CODING_AGENT_DIR` for a nonstandard home directory.
</details>
